# 🚀 MS Portfolio - Personal Bento Grid Dashboard

Welcome to the official repository of **MS Portfolio**, a modern, responsive, and highly interactive Bento Grid personal dashboard built to showcase web development projects, live coding stats, and data analytics dashboards.

🔗 **Live Demo:** [https://msdatahub58.github.io/WebDevelopment5/](https://msdatahub58.github.io/WebDevelopment5/)

---

## ✨ Features

- **🍱 Bento Grid Layout:** Clean, structured, and modern UI design inspired by contemporary web trends.
- **🎨 Dynamic Theme Switcher:** Fully customizable CSS custom properties (`:root`) allowing real-time switching between aesthetic themes (Neon Mint, Vaporwave Lavender, Coral Pink, and Emerald Green).
- **🎵 Built-in Lo-Fi Radio Player:** Embedded background music player featuring a custom spinning pixel-art vinyl disc animation and audio controls.
- **📁 Projects & Repositories Showcase:** Quick links to featured projects, sales analytics reports, and code repositories with custom hover glow effects.
- **📱 Fully Responsive:** Adaptive layout optimized for desktops, tablets, and mobile devices.
- **⚡ Custom Pixel Art Favicon:** Handcrafted retro-style "MS" pixel art branding integrated seamlessly.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup & structure.
- **CSS3:** Modern CSS Grid, Flexbox, CSS Variables, Animations, and Custom Scrollbars.
- **JavaScript (ES6):** Dynamic theme state management, DOM manipulation, and audio player controls.
- **Font Awesome:** Clean icon kit integration for crisp iconography.
